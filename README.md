# 不動産売買向けプロップテックガイド

不動産の売買を行う法人向けに、民間の法人契約型プロップテックサービスを業務プロセス別で整理した静的サイトです。

## 構成

- `index.html`: ページ本体
- `style.css`: デザイン
- `script.js`: フィルター処理、描画ロジック
- `data/services.csv`: サービス一覧の編集元
- `data/cases.csv`: 導入事例の編集元
- `data/news.csv`: ニュース一覧の編集元
- `data/data.js`: CSVから生成されるサイト表示用データ
- `scripts/build-data.mjs`: CSVから `data/data.js` を生成するスクリプト
- `assets/`: 画像とfavicon
- `netlify.toml`: Netlify公開設定

## データ更新手順

1. `data/services.csv`、`data/cases.csv`、`data/news.csv` を編集する
2. サービス詳細用の構造化列を初期補完する場合は `node scripts/enrich-services.mjs` を実行する
3. `node scripts/build-data.mjs` を実行する
4. 生成された `data/data.js` とサイト表示を確認する

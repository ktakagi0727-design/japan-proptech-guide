# 不動産売買向けプロップテックサービスガイド

不動産の売買を行う法人向けに、PropTechサービスを業務プロセス別に整理した静的サイトです。

## 構成

- `index.html`: ページ本体
- `style.css`: デザイン
- `script.js`: サービス一覧、ニュース、導入事例、フィルター処理
- `assets/`: 画像とfavicon
- `netlify.toml`: Netlify公開設定

## 今回の改善

- サイト名を「不動産売買向けプロップテックサービスガイド」に変更
- コンセプトを「不動産の売買を行う法人向け」に再構成
- Market View と How To Compare を削除
- Service Directory を「不動産売却」「不動産仲介」「不動産購入」「不動産開発/不動産運用」の4ステップで整理
- サービス名と提供会社名の表示位置を統一
- サービス数100件へのこだわりを外し、法人売買業務に合うサービスへ絞り込み
- 導入事例を、サービス提供会社別ではなく導入した会社別に再構成
- 不動産テック関連ニュース欄を日付順リストとページネーション付きに変更
- ニュースは業界紙・専門メディアなど中立寄りの情報源を中心に整理

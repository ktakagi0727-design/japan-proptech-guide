# Japan PropTech Guide

日本の不動産売買に関わるPropTechサービスを、カテゴリ、ニュース、導入事例と一緒に整理した静的サイトです。

## 構成

- `index.html`: ページ本体
- `style.css`: デザイン
- `script.js`: サービス一覧、ニュース、導入事例、フィルター処理
- `assets/`: 画像とfavicon
- `netlify.toml`: Netlify公開設定

## 今回の改善

- 掲載サービスを100件に拡張
- 売買仲介、売却査定、物件調査、電子契約、登記情報など売買関連を中心に再構成
- REMETIS、OFFICE RESEARCH、スマサテ、ア・ソコを追加
- マーケット情報、AI OCR、登記情報カテゴリを追加
- 不動産テック関連ニュース欄を日付順リストとページネーション付きに変更
- ニュースは業界紙・専門メディアなど中立寄りの情報源を中心に整理
- 導入事例をサービス単位ではなく会社単位に変更
- 1サービスに複数カテゴリが付く前提で分類・フィルター処理を調整
